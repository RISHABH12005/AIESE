# Student Hostel Management - Copilot Activity Project

A small C++ project for classroom activities using GitHub Copilot.

Modules:
- Student information
- Room availability and allocation
- Hostel fee calculation
- Login/security example

IMPORTANT: Some code is intentionally designed for classroom analysis.
Do not fix it before the activities.

Suggested activities:
1. Code Explanation
2. Debugging
3. Unit Test Generation
4. Security Analysis
5. Code Optimization / Complexity Analysis
6. Code Refactoring

Workflow:
Problem -> Ask Copilot -> Analyze response -> Test/verify -> Developer decision
