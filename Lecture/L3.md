## Develop an Online Examination System:-

### Manual:-

   - Need for which system Win, MacOS, Linux?

   - It should be Web or Application?

   - Supported browser like Chrome, Brave, Edge, Any other?

   - What kind od features does you need it for the system?


### Porompt:-

   - Ambiguous Requirement

   - Incomplet Reqirement

   - Conflicting Reqirement

   - Unrealistic Reqirement

   - Correct Reqirement

### Ans:-

	Type -> Requirement -> Problem
    Ambiguous Requirement -> The system should allow students to take exams easily. -> Easily is unclear and cannot be measured.
	Incomplete Requirement -> The system should display the exam questions. -> It does not specify how many questions, question types, time limit, or how answers are submitted.
	Conflicting Requirement -> Students must complete the exam within 60 minutes. & Students can pause the exam and continue it later. -> It is unclear whether the 60-minute timer continues while the exam is paused.
	Unrealistic Requirement -> The system must guarantee that no student can ever cheat during an online exam. -> It is technically impossible to guarantee zero cheating.
	Correct Requirement -> The system shall provide each registered student with a unique login. After authentication, the student shall be able to start the assigned exam. The exam shall have a 60-minute time limit, automatically submit when the time expires, and store the student's answers securely. -> Specific, measurable, testable, and technically achievable.
