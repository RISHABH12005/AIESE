# Task - 2 
Give this as Prompet to the AI

## Ans:-
```text
	1. Student Management Module

	Purpose: Manage all student information and hostel registration.

	Functions:

	Student registration
	Add, update, and delete student details
	View student information
	Assign students to rooms
	Track student hostel status
	Search student records

	Input: Student ID, name, course, year, contact details, guardian details, room details

	Output: Student profile, student list, hostel allocation details

	2. Room Management Module

	Purpose: Manage hostel rooms and room allocation.

	Functions:

	Add and update room details
	View available and occupied rooms
	Allocate rooms to students
	Vacate rooms
	Manage room capacity
	Track room occupancy

	Input: Room number, block, floor, room type, capacity, occupancy status

	Output: Room availability, room allocation details, occupancy report

	3. Fee Management Module

	Purpose: Manage hostel and mess fee payments.

	Functions:

	Record fee payments
	Calculate total fees
	Track paid and pending fees
	Generate payment receipts
	Calculate late fines
	View fee history

	Input: Student ID, fee type, amount, payment date, payment status

	Output: Fee receipt, payment history, pending-fee report

	4. Mess Management Module

	Purpose: Manage hostel mess services and student meal records.

	Functions:

	Register students for mess
	Manage monthly mess fees
	Maintain meal records
	Manage mess menu
	Track mess attendance
	Generate mess reports

	Input: Student ID, meal type, date, menu, mess fee, attendance

	Output: Mess attendance, monthly mess bill, menu, mess report

	5. Complaint Management Module

	Purpose: Manage and track student complaints.

	Functions:

	Submit complaints
	Categorize complaints
	Assign complaints to staff
	Track complaint status
	Update resolution details
	Close resolved complaints

	Input: Student ID, complaint type, description, date, priority

	Output: Complaint status, complaint history, pending/resolved complaint report

	Module Interaction
	              HOSTEL MANAGEMENT SYSTEM
	                       |
	       +---------------+---------------+
	       |               |               |
	    Student          Room            Fee
	  Management       Management      Management
	       |               |               |
	       +---------------+---------------+
	                       |
	                 Mess Management
	                       |
	              Complaint Management

	These five modules together provide the core functionality required for a Hostel Management System.
```
