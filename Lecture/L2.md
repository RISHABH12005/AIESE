# Task-2:-

## AI Prompet:-
	Generate Functional and non Functional requirement for a Library Management System

## Ans:-

###	Functional Requirements:-

	ID	    Requirement
	FR-01	The system shall allow users (Admin, Librarian, and Member) to register and log in securely.
	FR-02	The system shall authenticate users and provide role-based access control.
	FR-03	The system shall allow the librarian to add, update, delete, and view book records.
	FR-04	The system shall allow users to search books by title, author, ISBN, category, or publisher.
	FR-05	The system shall display the availability status of each book.
	FR-06	The system shall allow the librarian to issue books to registered members.
	FR-07	The system shall allow members to return borrowed books.
	FR-08	The system shall allow members to renew borrowed books, subject to library policies.
	FR-09	The system shall calculate overdue fines automatically based on the due date.
	FR-10	The system shall allow members to reserve books that are currently unavailable.
	FR-11	The system shall maintain member information, including borrowing history.
	FR-12	The system shall generate reports such as issued books, returned books, overdue books, fines collected, and inventory status.
	FR-13	The system shall send notifications or reminders for due dates, overdue books, and reserved book availability.
	FR-14	The system shall maintain transaction logs for all issue, return, renewal, and reservation activities.
	FR-15	The system shall support database backup and restoration to prevent data loss.

### Non-Functional Requirements:-

	ID	    Requirement
	NFR-01	The system shall respond to user requests (e.g., book search) within 2 seconds under normal conditions.
	NFR-02	The system shall support at least 500 concurrent users without significant performance degradation.
	NFR-03	The system shall ensure 99.9% availability, excluding scheduled maintenance.
	NFR-04	The system shall encrypt user passwords and sensitive information using secure encryption techniques.
	NFR-05	The system shall implement role-based access control to prevent unauthorized access.
	NFR-06	The system shall maintain data integrity and prevent duplicate or inconsistent records.
	NFR-07	The system shall perform automatic daily backups and allow recovery from backup files.
	NFR-08	The system shall be compatible with major web browsers (Chrome, Firefox, Edge, Safari).
	NFR-09	The system shall provide a responsive, user-friendly interface for desktop, tablet, and mobile devices.
	NFR-10	The system shall be scalable to support future growth in users, books, and transactions.
	NFR-11	The system shall maintain detailed audit logs for administrative and security-related activities.
	NFR-12	The system shall be maintainable, allowing updates and bug fixes without affecting existing functionality.
	NFR-13	The system shall comply with applicable privacy and data protection policies.
	NFR-14	The system shall recover from unexpected failures with minimal downtime and no data corruption.
	NFR-15	The system shall provide clear error messages and log system errors for troubleshooting.

###	Functional Requirements

	ID	    Requirement
	FR-01	The system shall allow authorized users to log in securely.
	FR-02	The system shall allow the operator to remotely control the drone.
	FR-03	The system shall capture real-time video and images using onboard cameras.
	FR-04	The system shall transmit live video and telemetry data to the ground control station.
	FR-05	The system shall record and store surveillance footage for later review.
	FR-06	The system shall provide GPS-based real-time location tracking of the drone.
	FR-07	The system shall support autonomous flight based on predefined waypoints.
	FR-08	The system shall detect and avoid obstacles during flight.
	FR-09	The system shall monitor battery level and notify the operator when the battery is low.
	FR-10	The system shall automatically return to the home location when the battery is critically low or communication is lost.
	FR-11	The system shall generate alerts when suspicious movement or predefined events are detected.
	FR-12	The system shall maintain flight logs, including route, altitude, speed, and mission details.
	FR-13	The system shall allow the operator to start, pause, resume, and terminate surveillance missions.
	FR-14	The system shall support day and night surveillance using appropriate camera sensors (e.g., RGB and thermal/night vision if equipped).
	FR-15	The system shall generate mission reports containing flight duration, coverage area, and recorded events.

###	Non-Functional Requirements

	ID	    Requirement
	NFR-01	The system shall transmit live video with minimal latency (e.g., less than 500 ms under normal conditions).
	NFR-02	The system shall provide at least 99% system availability during scheduled surveillance operations.
	NFR-03	The system shall encrypt communication between the drone and the ground control station.
	NFR-04	The system shall authenticate users and implement role-based access control.
	NFR-05	The system shall operate reliably under varying weather conditions within its specified operating limits.
	NFR-06	The system shall support stable flight in moderate wind conditions as specified by the drone manufacturer.
	NFR-07	The system shall maintain accurate GPS positioning within the supported accuracy limits.
	NFR-08	The system shall automatically recover from temporary communication failures whenever possible.
	NFR-09	The system shall be scalable to support multiple drones managed from a single control station.
	NFR-10	The system shall provide a user-friendly interface for mission planning and drone control.
	NFR-11	The system shall securely store surveillance data and prevent unauthorized access.
	NFR-12	The system shall maintain detailed audit logs of flights, operator actions, and system events.
	NFR-13	The system shall support regular software updates and maintenance without affecting stored mission data.
	NFR-14	The system shall be compatible with standard ground control software and supported communication protocols.
	NFR-15	The system shall ensure safe operation by complying with applicable aviation regulations and implementing fail-safe mechanisms (e.g., Return-to-Home and emergency landing).
