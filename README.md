# Artificial Intelligence Enabled Software Engineering (AIESE)

Coursework, lecture notes, assignments, and practical activities for **Artificial Intelligence Enabled Software Engineering**.

## Getting Started

1. Browse the section tables above and open the lecture, assignment, or activity you need.
2. For code-based work, open the relevant source files in the linked folder.
3. Check each folder's own README, where available, for project-specific information.

### Working with C++ examples

A C++ compiler such as **G++** or **Clang** is needed to compile the source files. For example, from the repository root:

```bash
g++ "Lecture/L10/calculator.cpp" -o calculator
./calculator
```

This command is an example for the calculator source only; other exercises may have different build or runtime requirements.

### Working with Python activities

Python-based activities may have their own dependencies and setup steps. Review the activity folder before running its scripts, and keep API credentials in environment variables or a local `.env` file that is not committed to version control.
