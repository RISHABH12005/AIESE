# Quiz Assignment 1

## Questions

1. What is AI-assisted Software Engineering?

2. What is prompt engineering?

3. What is automated test case generation?

4. What is defect prediction?

5. What is anomaly detection?

## Answers

1. AI-assisted Software Engineering is the use of artificial intelligence tools to support software development activities such as requirements analysis, coding, debugging, testing, documentation, and maintenance. These tools assist developers, but human review and decision-making remain important.

2. Prompt engineering is the practice of designing, refining, and organizing instructions given to an AI system so that it produces accurate, relevant, and useful results.

3. Automated test case generation is the use of software tools or AI to create test cases automatically from requirements, source code, models, or program behavior. It helps improve test coverage and reduce manual effort.

4. Defect prediction is the use of historical software data, code metrics, and machine-learning techniques to identify parts of a software system that are likely to contain defects.

5. Anomaly detection is the process of identifying unusual patterns or behaviors that differ significantly from normal system activity. In software engineering, it can be used to detect failures, security threats, performance problems, or unexpected application behavior.
