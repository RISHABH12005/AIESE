# Quiz Assignment 2

## Questions

1. What is intelligent debugging?

2. What is regression testing?

3. What is Software Quality Assurance (SQA)?

4. What does HTTP status code 200 indicate in Postman?

5. What is an assertion in API testing?

## Answers

1. **Intelligent debugging** is a systematic approach to identifying, analysing, and fixing software defects using evidence such as logs, error messages, test results, and program behaviour. It helps developers locate the root cause of a problem instead of merely correcting its visible symptoms.

2. **Regression testing** is the process of re-running previously executed tests after a software change to ensure that existing features still work correctly and that the change has not introduced new defects.

3. **Software Quality Assurance (SQA)** is a planned and systematic set of activities used to ensure that software development processes and products meet specified quality standards. It focuses on preventing defects through standards, reviews, testing, and process improvement.

4. **HTTP status code 200** indicates that the request was successful and the server processed it successfully. In Postman, it confirms the HTTP-level success of the request, but it does not automatically guarantee that the response data is correct.

5. **An assertion in API testing** is a condition or check used to verify that an API response meets an expected result. For example, an assertion can check the status code, response time, content type, or value of a particular JSON field.
